[pam](https://github.com/arup-group/pam) is a Python library for population activity modelling — reading, modifying, and writing activity-travel demand data. It supports a range of input formats and is designed for use in transport and urban modelling workflows.

Published in the [Journal of Open Source Software](https://joss.theoj.org/papers/10.21105/joss.06097).
